AutoIntegrate is a free PixInsight script that runs the whole image processing workflow for you. Add your light files, press Run, and you get integrated images and an automatically processed final image.

It works with mono LRGB, color/OSC/DSLR and narrowband data, calibrated or not.

PixInsight repository link
https://ruuth.xyz/autointegrate/
In PixInsight, add this to Resources / Updates / Manage Repositories, then Check for Updates and restart. See installing.

Three steps to your first image

Install

Add the repository link above to PixInsight and check for updates. AutoIntegrate appears in the Script / AutoIntegrate menu.

Add files

On the Files tab, add your light files, or a whole directory. Bias, dark and flat files are optional.

Run

Press Run. Default options work well for a first try. The live flowchart shows what the script is doing.

The script starts in simple mode, which shows only the most important options. Built-in tutorials walk you through the dialog step by step. See Getting started for details.

What happens when you press Run

AutoIntegrate runs the same steps you would run manually in PixInsight. Click a step to read more about it.

Calibratewith bias, darks and flats if given Measureweight and filter subframes Alignstars or comet Integratestack with pixel rejection Combinechannels or narrowband palette Gradientsremove light pollution Colorcolor calibration Denoisenoise reduction Stretchlinear to non-linear Final imageAutoRGB or AutoLRGB

on by default optional result

After the run you can continue with enhancements such as star reduction, sharpening or color adjustments, or rerun only part of the workflow with AutoContinue. AutoIntegrate can also use external tools like BlurXTerminator, NoiseXTerminator, StarXTerminator, GraXpert and StarNet if you have them installed.

Is AutoIntegrate for me?

  • New to PixInsight? Get a good image right away, before learning all the details.
  • Using remote telescopes or prepared masters? Quick calibration, alignment and integration of pre-calibrated data. Note that it is not a replacement for WBPP.
  • Experienced user? Get a quick look at the data to check calibration, gradients and color balance before spending a day on manual processing, then continue manually from any intermediate image.
